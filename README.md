# Electro Monte Grande

Catálogo estático publicado en GitHub Pages.

## Sitio

- GitHub Pages: https://mercadopagolink.github.io/electro-monte-grande-catalogo/
- Dominio: https://electro-mg.com/

## Qué incluye

- 200 productos: 80 celulares, 60 Smart TV y 60 aires acondicionados
- Precios de referencia en pesos argentinos (agosto 2026)
- Filtro por categoría y marca, búsqueda y calculadora de frigorías
- Consulta por WhatsApp

Los precios y descripciones son referencia de mercado local. Confirmá stock y valor por WhatsApp.

Las fotos son imágenes libres (Unsplash), no capturas de tiendas.

## Cómo editar

- WhatsApp y textos: `js/config.js` (número real, solo dígitos con 54)
- Productos: `js/rows-1.js` a `js/rows-4.js`
- Colores / layout: `css/estilo.css`

Commit en `main` y en uno o dos minutos se publica.
