# Electro Monte Grande

Catálogo estático publicado en GitHub Pages.

## Sitio

https://mercadopagolink.github.io/electro-monte-grande-catalogo/

El dominio electro-mg.com quedó desactivado porque el certificado HTTPS no coincide (el celular muestra aviso de seguridad). Usá el enlace de GitHub Pages.

## Qué incluye

- 200 productos: 80 celulares, 60 Smart TV y 60 aires acondicionados
- Ficha de cada producto (foto, descripción, specs, precio)
- Filtro por categoría y marca, búsqueda y calculadora de frigorías
- Consulta por WhatsApp

## Cómo editar

- WhatsApp y textos: `js/config.js` (número real, solo dígitos con 54)
- Productos: `js/rows-1.js` a `js/rows-4.js`
